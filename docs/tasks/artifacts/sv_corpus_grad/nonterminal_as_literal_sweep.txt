⚠️ WHAT THIS SWEEP DOES NOT ANSWER, stated rather than implied:
   - WHICH nonterminal each site meant. The `candidate` line narrows it mechanically and says
     so when it cannot close it. ⛔⛔ A NAME NEIGHBOUR IS NOT A REPAIR, and this population
     contains the counter-example that proves it: `class_qualifier`'s nearest name is
     `class_item_qualifier`, and in IEEE 1800 those are DIFFERENT productions —
     `class_item_qualifier ::= static | protected | local` versus
     `class_qualifier ::= [ local:: ] [ implicit_class_handle . | class_scope ]`.
     Substituting the neighbour would replace an unreachable alternative with a WRONG one,
     which is worse: unreachable under-accepts, wrong mis-parses. Only the LRM text decides.
   - whether re-pointing a reference is a one-line fix. It is not, at least once: the sv_2017
     cross-body shape demands a `;` after EVERY item, so the repair must mirror the sv_2023
     pair. Every fix here is ACCEPT-WIDENING and owes the full ceremony.
   - ⛔ WHETHER THE CONSTRUCT IS REJECTED. This sweep measures REACHABILITY of an
     ALTERNATIVE, and a construct can be reachable through a DIFFERENT production, so
     `unreachable` does NOT imply `rejected`. This bullet asserted the implication until
     `.13c.2f`, and pinning a minimal input per site refuted it: of the five sites the
     sweep has ever listed, THREE rejected (`function_declaraton`, both `PATHPULSE$`
     forms — all three now fixed) and the two that remain, `class_qualifier` and
     `tx_path_delay_expression`, ACCEPT today through other productions. ⇒ every row here
     owes a pinned REJECT before it is called an under-acceptance, and a row with none is
     an unreachable alternative — still a defect, because the grammar claims support it
     does not deliver, but not axis-2 mass.
