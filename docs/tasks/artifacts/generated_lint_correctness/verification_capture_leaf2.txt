⚠️ THE FOLD CREATED A FRESH INSTANCE OF THE CLASS IT REMOVES — CAUGHT BY RE-MEASURING
--------------------------------------------------------------------------------

The first associativity fold emitted, for a left-associative rule:

    } else if candidate_priority < best_priority {
        false
    } else {
        false          // <- the folded left tie-break
    }

which is `clippy::needless_bool`, measured at **7,482 new warnings** (generated
stage 80,402 -> 93,822). Merging the two arms then left the tail as
`else if candidate_priority > best_priority { true } else { false }` — the OTHER
`needless_bool` phrasing, and still 7,482 of them. The emission now collapses
the tail to the comparison itself:

    } else if candidate_end < best_end {
        false
    } else {
        candidate_priority > best_priority     // `<` and `==` both answer "no"
    }

Final count: `needless_bool` **0**, generated warnings **78,858** — below the
`.1` baseline. The lesson, banked in the leaf: a fold that only watches the ERROR
count can silently ship thousands of instances of the very shape it is removing;
re-measure the WHOLE lint census, not the gate's verdict.
