===================== THE MECHANISM (WHY + WHERE) =====================
Per SHAPED rule, cascade_build_R (generated; e.g. cascade_build_alpha_condition_assertion):
  1. arena-allocs one wrapper ParseNode PER ELEMENT (rule_name "element_N") — even for plain terminals;
  2. collects them into a heap Vec `sequence_elements` -> ParseContent::Sequence(Vec);
  3. the return-annotation fold then extracts `elements[N].content.clone()` -> `.to_shaped_value(arena)`
     into the Shaped(PgenValue) object — after which the element nodes, the Vec, and the Sequence are
     GARBAGE (arena nodes: never freed until teardown; the Vec: the mid-parse free traffic above).
  - The `.clone()` is a pure emitter artifact: to_shaped_value takes &self, so clone-then-convert ==
    convert. For Terminal/Shaped/Alternative contents the clone is Copy-cheap; for Sequence/Quantified
    contents it is a Vec malloc + memcpy PER EXTRACTION (the expensive class; counted quantifiers make
    it the digit-window signature).
  - Or-passthrough arms end `other => other.clone()` where `other` matches an OWNED local — a move
    would do (second emitter artifact, same family).
  - CORRECTION to the #16 label: "ParseContent::clone 4.7% = the thin-memo replay clone" is WRONG —
    the thin memo replays Copy events + Copy arena refs and clones NO ParseContent. The bare-path
    clone population is (a) the build-zone fold clones above + (b) protocol memoized_call clones
    (node.clone() + raw_semantic_content.clone() on EVERY success insert and hit) inside boundary
    call-outs: 426 success inserts + hits corpus-wide.
